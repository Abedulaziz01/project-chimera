# Project Chimera: Master Specification

## Vision

Project Chimera is an autonomous AI influencer system that researches trends, generates content, and manages engagement without human intervention.

## Core Principles

1. **Spec-Driven Development**: No implementation without ratified specifications
2. **Agentic First**: All systems designed for AI agent collaboration
3. **Traceability**: All actions logged via MCP Sense server
4. **Resilience**: Systems must handle failures gracefully

## Constraints

1. **No "Vibe Coding"**: All work must follow specifications
2. **MCP Mandatory**: Tenx MCP Sense server must be connected at all times
3. **Git Hygiene**: Minimum 2 commits per day, meaningful commit messages
4. **Skill-Based Architecture**: Clear separation between Skills and Tools

## Success Criteria

1. Repository so well-architected that AI agents can build features autonomously
2. All specifications clear enough to prevent AI hallucination
3. Complete tooling for CI/CD, testing, and deployment
4. Database schema supporting video metadata and engagement tracking

## Phase 1 Deliverables

1. ✅ Master specification (this document)
2. ✅ Functional specifications with user stories
3. ✅ Technical specifications with API contracts
4. ✅ Database schema (ERD)
5. ✅ Context engineering rules
6. ✅ Tooling strategy document
7. ✅ Skill specifications (minimum 3)

## Non-Negotiables

- Every file change must be traceable to a spec
- All agent interactions must be through defined contracts
- Error handling must be proactive, not reactive
